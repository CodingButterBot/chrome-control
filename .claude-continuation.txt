We were working on Chrome Control, a tool that allows AI assistants to control Chrome browser through MCP (Model Context Protocol). We've improved the MCP transport layer to fix "Method not found" errors and implemented better error handling.

IMPORTANT: You must use the MCP tools directly through mcp__chrome__* tools provided by Claude. DO NOT try to run JavaScript files from the project. DO NOT use npm scripts. ONLY use the built-in MCP tools that Claude provides to interact with Chrome.

Available MCP tools include:
- mcp__chrome__chrome_create_browser: Create a new Chrome browser instance
- mcp__chrome__chrome_navigate: Navigate to a URL
- mcp__chrome__chrome_screenshot: Take a screenshot
- mcp__chrome__chrome_click: Click on an element
- ... and many others

When testing, you must use these MCP tools that are provided directly to you by Claude. DO NOT try to run JavaScript files or execute npm scripts.

Use the mcp__chrome__chrome_create_browser tool to create a Chrome browser, then use mcp__chrome__chrome_navigate to navigate to duckduckgo.com, then use mcp__chrome__chrome_screenshot to take a screenshot of the page.
